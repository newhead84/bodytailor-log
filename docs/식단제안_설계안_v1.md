# BodyTailor Log 식단 제안 설계안 v1 (2026-11-12)

> Phase2 새 기능. 기록을 쓰게 하는 앱이 아니라, 이미 쌓인 운동·체중 기록을 읽어 하루 식단을 **제안**한다.
> 원칙: 근거 있는 숫자 + 편의점·간편식으로도 지킬 수 있는 구성. 규칙 계산이며 'AI' 표현을 쓰지 않는다.
> 이 문서는 연구·지침을 정리한 설계안이다. **별도 검수 없이 진행(2026-11-12 사용자 결정)**: 대신 화면 '이렇게 정한 이유'에 학술 자료·공공 데이터가 근거임과 일반 정보임을 분명히 적는다.
> 영양값은 사용자가 첨부하는 식약처 '전국통합식품영양성분정보(원재료성 식품·음식)' 표준데이터 파일에서 그대로 옮기고 재료마다 출처 코드를 남긴다(추정값 금지).

## 2. 계산

### 2-1. 하루 목표 칼로리
1. 기초대사량 = Mifflin-St Jeor(성별·나이·키·체중, `users.onboarding`).
2. 일상 활동 = 기초대사량 × 1.3(앉아서 일하는 기준, 사용자가 '많이 걷는 일'을 고르면 1.45).
3. 운동 소모 = 최근 28일 운동 기록 `caloriesKcal` 합 ÷ 28(이미 저장된 값, 추가 읽기 없음 - 기기 보관본 사용).
4. 유지 칼로리 = 2 + 3. 1순위 목표로 조정:
   - 체지방 줄이기: 유지의 −15%(체지방률을 알고 25% 넘으면 −20%), **적자는 500kcal를 넘지 않음**.
   - 근육·근력 키우기: 가입 8주 미만·경력 1년 미만 +15%, 그 밖 +10%(숙련자 보수적으로).
   - 체력·건강, 뼈·관절, 자세·코어: 유지.
5. 하한: 기초대사량, 그리고 여성 1200·남성 1500kcal 중 높은 값 아래로는 내리지 않는다.
6. **만 19세 미만은 감량 적자를 걸지 않는다**(유지만, 앱은 14세 이상 사용 가능).

### 2-2. 체중 추이로 보정(사용자 선택: 자동 보정)
- `users.weightLog`에서 최근 14일 안의 기록 2개 이상과 그 전 14일 기록을 비교해 주간 변화율(%)을 낸다. 하루 변동을 줄이려고 구간 평균끼리 비교.
- 목표 속도: 감량 주 −0.5 ~ −1.0%, 증량 주 +0.25 ~ +0.5%, 유지 ±0.25%.
- 범위보다 느리면 ∓100kcal, 빠르면 ±150kcal(빠른 감량은 근손실 쪽이라 더 크게 되돌림). 2주에 한 번만, 누적 ±300kcal까지.
- 체중 기록이 없거나 부족하면 보정하지 않고 '체중을 주 2번 이상 적으면 식단이 맞춰져요' 안내.
- 4–8주 넘게 변화가 없으면 정체 안내(ISSN 2026: 정체는 섭취 과소 기록·적응 둘 다 원인) - 보정을 더 크게 하지 않고 '지킬 수 있는 만큼'을 묻는다.

### 2-3. 영양소
- 단백질(g/kg): 체력·건강 1.4 / 근육 1.8 / 감량 2.0(체지방률 낮으면 2.2). 체중은 BMI 30 이상이면 키 기준 표준체중(BMI 25) 체중으로 계산(과다 처방 방지).
- 지방: 하루 칼로리의 25%(최소 0.6g/kg), 15–30% 안.
- 탄수화물: 나머지. 50% 아래로 내려가면(고단백 감량) 그 사실을 '이렇게 정한 이유'에 적는다 - 국민 기준은 일반 인구용, 근력 운동 감량은 스포츠영양 기준을 따랐다고.
- 식이섬유 25g 이상, 나트륨 2,300mg 이하를 하루 점검 항목으로(편의점 메뉴는 나트륨이 높아 고를 때 감점).
- 운동하는 날·쉬는 날: 칼로리는 같게 두고 운동하는 날 운동 전후 끼니에 탄수화물을 조금 더 몰아 준다(총량 변화 없이 배치만).

### 2-4. 끼니 나누기
- 기본 3끼 + 간식 1(사용자가 2끼+간식 / 3끼 / 3끼+간식 2 고름).
- 칼로리: 아침 25 · 점심 35 · 저녁 30 · 간식 10%(끼니 수에 따라 다시 나눔).
- 단백질: 끼니마다 0.4g/kg 이상(최소 20g), 간식은 10–20g.
- 운동 시간대: 최근 기록의 시작 시각 평균으로 '운동 전 끼니(1–3시간 전)'·'운동 후 끼니'를 표시.

## 3. 레시피 DB

### 3-1. 구조(앱에 넣는 정적 파일, Firestore 읽기 없음)
```
utils/nutrition/foods.js      재료 약 150개: { id, name, kcal, p, c, f, fiber, na (100g당), unit: {개·컵·팩: g}, src: 'MFDS:코드' }
utils/nutrition/meals.js      메뉴 약 150개: { id, name, slot: [아침|점심|저녁|간식], mode: 편의점|간편|요리|외식,
                              minutes, items: [{ food, g }], tags: [한식·양식·도시락·매운·국물…], avoid: [돼지·소·해산물·유제품·달걀·글루텐…],
                              steps?(요리만, 직접 작성 문장) }
utils/nutrition/plan.js       목표 계산·끼니 배분·메뉴 고르기·양 맞추기
```
- 영양값은 재료 g에서 자동 계산(메뉴마다 숫자를 손으로 적지 않음 → 재료 값 하나 고치면 모든 메뉴가 맞춰짐).
- 상품명·상표는 쓰지 않는다(예: '편의점 닭가슴살 1팩(100g)', '단백질 음료 1팩(단백질 20g 안팎)'). 실제 제품은 라벨을 보라는 한 줄.

### 3-2. 구성(약 150개, 요리를 해야 하는 메뉴는 1/4 이하)
| 방식 | 개수 | 예 |
|---|---|---|
| 편의점 조합 | 약 45 | 삼각김밥 1 + 닭가슴살 1팩 + 샐러드 / 바나나 + 그릭요거트 + 삶은 달걀 2 / 편의점 도시락 고르는 법(밥 반 남기기) |
| 간편식(전자레인지·5분) | 약 40 | 즉석밥 + 참치캔 + 김 + 냉동 브로콜리 / 오트밀 + 우유 + 견과 / 냉동 닭가슴살 볶음밥 |
| 외식 고르는 법 | 약 20 | 국밥: 공기밥 2/3 + 고기 더 / 김밥집: 참치김밥 + 계란 / 구내식당 식판 채우는 순서 |
| 요리(15–30분) | 약 30 | 닭가슴살 덮밥, 두부 스테이크, 연어 포케, 소고기 미역국 |
| 고단백 간식 | 약 15 | 우유 + 삶은 달걀, 두유 + 견과, 단백질 음료 |
- 요리 문장(만드는 법)은 직접 쓴다(저작권). 외부 레시피 사이트 문장을 옮기지 않는다.

### 3-3. 메뉴 고르기
1. 끼니 목표(칼로리·단백질)에 맞춰 후보 점수: 단백질 부족 감점 > 칼로리 차이 > 나트륨 > 같은 재료 연속.
2. 양 맞추기: 0.75 · 1 · 1.25 · 1.5인분(밥·빵 같은 탄수화물 재료만 따로 조절 가능 - '밥 반 공기').
3. 다양성: 같은 끼니에 14일 안에 나온 메뉴 제외, 하루 안에 같은 주재료(닭가슴살 등) 2번까지, 방식(편의점·간편·요리)은 사용자 비율 설정을 따름.
4. '바꾸기': 같은 끼니 다른 후보(목표에 가까운 순), '편의점으로'·'요리로' 빠른 전환.
5. 기록 없이도 하루 합계(칼로리·단백질·나트륨)를 보여 주고, 목표의 ±10% 안이면 '맞춤'.
6. 제안 이력은 이 기기에만(localStorage) - 저장·읽기 없음.

## 4. 취향 설정(`users.diet`, 처음 한 번 짧게)
- 식사 방식 비율: 대부분 편의점·간편 / 섞어서 / 요리 자주.
- 안 먹는 것(취향): 돼지고기·소고기·해산물·유제품·달걀·매운 음식·밀가루. **알레르기·질환은 묻지 않는다**(건강 정보 = 동의 범위 밖).
- 하루 끼니 수, 일상 활동(앉아서·많이 걷는 일), 요리 시간(5·15·30분).
- 저장: `users.diet { v, style, avoid[], meals, activity, cookMin, adj, adjAt }` - rules `userFieldsOk`에 크기 검사(avoid ≤10, adj −300~300 정수) 추가 → **배포 직후 콘솔 규칙 게시 필요**.
- 담당 트레이너: users 문서를 이미 읽을 수 있으니 '식단 목표(칼로리·단백질)'를 회원 화면에 한 줄로(선택, 2단계).

## 5. 화면
- HOME '오늘 식단' 카드: 칼로리·단백질 목표 + 다음 끼니 하나(바꾸기). 처음이면 '식단 맞추기' 시작.
- 식단 화면(ScreenHeader): 하루 합계 막대 → 끼니 카드(메뉴·양·칼로리·단백질·조리 시간 칩·바꾸기) → '이렇게 정한 이유'(접기: 계산식, 출처 우리말·연도, 건강 면책) → 취향 바꾸기.
- 식단 설명 칩: '손바닥 크기 고기 = 단백질 약 25g' 같은 눈대중 안내(계량 없이 따라 하게).
- 운동 완료 요약에 '운동 후 끼니' 한 줄(단백질 20–40g).

## 6. 안전·법
- 건강 면책: 운동 영양 정보이며 진단·치료가 아님. 질환(신장·당뇨 등)·임신·수유 중이면 의사·영양사 상담.
- 체중 감량 문구는 칼로리 숫자를 강조하지 않고 단백질·끼니 구성 중심. '치팅'·'죄책감' 표현 쓰지 않음.
- 감량 적자는 500kcal 이하, 1200/1500kcal 하한, 19세 미만 감량 없음.
- 처리방침: 새로 받는 건 취향(안 먹는 음식·끼니 수)뿐이라 건강 정보 아님 → 항목만 추가, `CONSENT_VERSION`은 회원 받기 직전 결정(기존 방침과 같음).
